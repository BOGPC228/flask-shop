# TechStore — Интернет-магазин на Flask + PostgreSQL

Полнофункциональный интернет-магазин с каталогом, фильтрацией по категориям и тегам, учётом остатков на складе, промокодами, корзиной (`localStorage`), системой ролей (`user`, `manager`, `admin`) и расширенной админ-панелью.

## Возможности админ-панели (роль `admin`)
- **Статистика** — выручка, количество заказов, средний чек, топ продаваемых товаров.
- **Экспорт в Excel / CSV** — выгрузка заказов и каталога товаров в один клик.
- **Товары и склад** — управление каталогом, фото с предпросмотром, остатки на складе (автосписание при заказе), категории и теги.
- **Заказы** — смена статусов и удаление заказов.
- **Категории** — создание и удаление разделов каталога.
- **Промокоды** — скидки в %, лимит активаций, срок действия, включение/выключение.
- **Пользователи** — назначение ролей (`Покупатель`, `Менеджер`, `Администратор`) и блокировка.
- **Логи** — журнал всех действий админов и менеджеров.
- **Настройки** — смена названия сайта, баннера, контактов и стоимости доставки без правки кода.

## Быстрый запуск локально

1. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   ```
2. Запустите сервер:
   ```bash
   python app.py
   ```
3. Откройте `http://127.0.0.1:5000`.
4. Доступ администратора по умолчанию: **`admin`** / **`admin123`** или **`admin`**.
5. Тестовый промокод по умолчанию: **`SALE15`** (скидка 15%).
